# beads-task-management

Inspect 'bd help' and verify installed Beads version. Ensure task graph is initialized by the CLI, not by manually creating .beads files. Start from assigned task; inspect blockers/dependencies, scope and acceptance criteria. Link changes and evidence to task; preserve IDs through handoffs. Distinguish task complete from deployed/verified. When blocked, state blocker and required action, not a fictitious pass. Reference: https://github.com/gastownhall/beads

## Output evidence
Report verified environment/version, affected paths, tests and actual results, unresolved risks, next Beads task and approvals required. Never claim an untested integration succeeded.
